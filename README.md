# MiTV

Начальная основа проекта на Python 3.12+. Прикладные функции пока не реализованы.

## Подготовка

```sh
python3 -m venv .venv
```

Внешние зависимости и секреты не требуются.

## Запуск

```sh
.venv/bin/python -m mitv --help
.venv/bin/python -m mitv --version
```

## Проверка

```sh
.venv/bin/python -m unittest discover -s tests -v
```
